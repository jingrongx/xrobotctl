# 应用内自动更新

XRobot 中枢内置了更新中心，打开 App 即可用。启动后会自动检测新版本（可在设置里关闭），发现新版会发通知；点进更新中心可查看线路测速、一键下载安装。

## 界面

App 启动后是横屏主界面，底部两个 Tab：

- **控制**：四色方向键（前进蓝 / 后退紫 / 左转青 / 右转琥珀 / 停止红）、头部控制、快捷动作（找红球 / 走方形 / 转一圈）、命令日志。全部直接调本地命令队列，和 HTTP 调用走同一条串行通道，不会冲突。
- **更新中心**：版本卡片、三色下载线路（绿=官方、琥珀=镜像 A、紫=镜像 B，★=最快）、检查更新 / 一键更新按钮、进度条、三个开关、实时日志。

## 工作流程

1. **检测**：`GET https://api.github.com/repos/jingrongx/xrobotctl/releases/latest`，取最新 tag 与 APK 资产。仓库是公开的，无需 token。
2. **版本比较**：tag `v1.0.2` → `versionCode 10002`（`major*10000+minor*100+patch`），与本机 `versionCode` 比较； bigger 才算新版。可"跳过当前版本"。
3. **测速**：对官方源 + 3 条国内镜像（ghfast.top / gh-proxy.com / ghproxy.net）+ 可选自定义代理，逐条发 HEAD（不支持则 Range GET）测首包延迟，按快慢排序。
4. **下载**：选最快线路，流式写入 app 缓存目录并回调进度；校验文件大小。
5. **安装**：
   - 有 root 且勾选"Root 静默装" → `su` 调 `pm install -r` 静默安装，无需手动点击；
   - root 失败或无 root → 走 `PackageInstaller` 会话提交，弹出系统安装器，由用户手动点"安装"。

## 设置项

| 开关 | 默认 | 说明 |
|---|---|---|
| 启动自动检测 | 开 | App 启动时后台检测，发现新版发通知（不自动下载） |
| 下载后自动装 | 开 | 下载完成后立即安装；关闭则下载完停在日志提示 |
| Root 静默装 | 开 | 有 root 时静默安装；关闭或无 root 则弹系统安装器手动点 |
| 代理前缀 | 空 | 留空自动测速；也可填自定义镜像前缀，如 `https://ghfast.top/` |

## 版本号对齐

发版 workflow 在构建前会把 tag 号写进 `AndroidManifest.xml` 的 `versionCode` / `versionName`（见 [发版说明](发版说明.md)），所以 Release 版本与 App 内版本始终一致。app 端 `Updater.codeOfTag()` 与 workflow 用的是同一套换算公式：`v1.0.2 → 10002`。

## 权限说明

新增了 `INSTALL_PACKAGES` 相关的系统能力通过 `PackageInstaller` 会话使用；平台签名保证 ROBOT 权限不受影响。自动更新只读公开 Release，不上传任何设备信息。

## 已知限制

- 检测走 GitHub API，未认证请求有频率限制（约 60 次/小时/IP），个人设备足够；启动检测已延迟 3 秒并失败静默，不影响控制功能。
- 国内镜像是第三方公共代理，可用性会波动；App 每次都逐条实测，坏的线路自动跳过。也可在设置里填自己的代理前缀。
- 无 root 设备安装需手动点确认（Android 系统限制，无法静默）。
