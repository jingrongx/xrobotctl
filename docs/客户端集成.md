# 客户端集成指南

## 引入（三选一）

**方式 A — 拷贝源文件（最简单）**：把 `client/src/com/xrobot/client/XRobot.java` 拷进你的工程。零依赖，只用到 android.jar。

**方式 B — 引用 jar**：`./tools/build_client.sh` 生成 `client/out/xrobot-client.jar`，放进 `app/libs/` 并添加依赖。

**方式 C — 命令行/脚本**：不需要客户端，直接 `adb shell content call`（见 [命令协议](命令协议.md)）。

不需要在 Manifest 声明任何权限或 query。

## 基本用法

```java
XRobot robot = XRobot.get(context);          // 单例，可重复调用

// 移动：dist 恒为正，speed 负=后退
robot.move(30);          // 前进 30cm（默认 8cm/s）
robot.move(30, 15);      // 前进 30cm，15cm/s
robot.move(30, -10);     // 后退 30cm

// 转向：正=左，负=右
robot.turn(90);          // 左转 90°（默认 60°/s）
robot.turn(-90);         // 右转 90°（内部换算成等效左转）

// 头部：−23 ~ +25，speed 2~30
robot.head(25);          // 抬头
robot.head(-10);         // 低头

robot.stop();            // 急停
```

## 返回结果

```java
XRobot.Result r = robot.move(30, 10);
if (r.ok) {
    // 已下发
} else {
    Log.w("app", r.msg);   // 如 "驱动 visbot 不支持能力: xxx"
}
```

中枢进程没装/没起来时，`r.ok=false`，`r.msg` 会明确提示"未找到 XRobot 中枢"。

## 能力发现（多机器人关键）

不同机器人能力不同。调用前先查，避免在不支持的机型上报错：

```java
String[] caps = robot.capabilities();
if (Arrays.asList(caps).contains("head")) {
    robot.head(25);
} else {
    // 该机型没有头部舵机，走降级逻辑
}
```

`robot.ping()` 返回当前驱动 id 和就绪状态（读 `r.raw.getString("driver")` / `getBoolean("ready")`）。

## 视觉导航

```java
robot.gotoColor("red");   // 找红色目标，闭环走过去，到达自动停
robot.detect("red");      // 只检测不驱动（标定）
robot.stop();             // 任何时候可中断
```

注意：视觉需要相机，会拉起中枢的界面到前台；这是 Android 相机前台策略决定，无法纯后台。

## 常见问题

- **调用总是失败**：确认中枢 APK 已装、已打开过一次、进程没被 force-stop。
- **开机后第一次失败**：SDK 初始化需要一两秒，重试一次即可（`ping()` 等到 `ready=true`）。
- **右转不准**：小方头机械打滑，驱动内部已换算成等效左转；精确角度用视觉闭环 `gotoColor`。
- **旅游宝等旧调用方**：旧 authority `com.visbot.robotctl.api` 仍保留，无需改动。
